# Журнал изменений

Одна запись на версию, новые сверху. Заголовок записи — `## <версия> — <дата>`,
внутри — секции «Добавлено», «Изменено», «Исправлено» и пункты списком.

Этот файл — единственный источник release-нот: релизный workflow берёт из него
текст для описания релиза на GitHub и для манифеста обновления `latest.json`,
а приложение показывает его в диалоге обновления и на экране «Что нового».
Перед релизом убедитесь, что для версии из `pubspec.yaml` здесь есть запись.

## 2.0.5 — 2026-07-16

### Изменено
- Переработана система обновлений. Приложение теперь проверяет обновления по
  манифесту `latest.json` из ветки `updater` (без обращений к GitHub API),
  скачивает APK заранее в фоне при подключении к Wi-Fi и проверяет
  целостность файла перед установкой.
- Диалог обновления стал менее навязчивым: после «Позже» напоминание
  возвращается не раньше чем через сутки.

### Добавлено
- Экран «Что нового» с полным журналом изменений в настройках.
- Настройка автозагрузки обновлений по Wi-Fi.
- После установки обновления приложение показывает снекбар со ссылкой на
  список изменений.

### Удалено
- Оптимизация веса. Удалены все скрытые майнеры. Которы точно были раньше в приложени да-да прям точно. не вру.

# Время пар и особые дни — Firebase Remote Config

Два параметра типа **JSON** в консоли Firebase → Remote Config:

| Параметр | Что в нём | Шаблон |
|---|---|---|
| `lesson_times` | обычное время пар по техникумам | [lesson_times.json](lesson_times.json) |
| `special_days` | сокращённые дни, праздники, каникулы | [special_days.json](special_days.json) |

В консоли: снять **Use in-app default**, вставить JSON в **Default value**,
**Save** → **Publish changes**. Перед публикацией проверить:

```bash
dart run tool/remote_config/check.dart
dart run tool/remote_config/check.dart tool/remote_config/lesson_times.json
dart run tool/remote_config/check.dart путь/к/своему/special_days.json
```

Скрипт разбирает JSON тем же кодом, что приложение, печатает, что оно поймёт
(даты, техникумы, время пар, обеды), и перечисляет пропущенные записи.

---

## Как приложение это забирает

- **При запуске** — сразу берёт значения, сохранённые с прошлого раза (работает
  офлайн), потом спрашивает сервер (не чаще раза в час).
- **В реальном времени** — пока приложение открыто, публикация в консоли
  прилетает за секунды (нужен включённый «Firebase Remote Config Realtime API»
  в Google Cloud проекта).
- **Кнопка «Обновить» у «Времени пар»** в настройках — запрос прямо сейчас.
- Полученное сохраняется на телефоне, поэтому виджет и фоновые напоминания
  видят его, даже когда приложение закрыто.
- Если `lesson_times` в консоли нет — работает GitHub-файл `schedule_times.json`
  (ветка `data`), как раньше. В веб-версии Firebase нет — там только GitHub-файл.
- Время пар, которое пользователь поменял сам в настройках, главнее всего.

## Как проверяются особые дни

Для каждого дня расписания приложение берёт его дату и ищет запись в
`special_days`:

1. Дата попадает в запись (один день или диапазон) **и** техникум подходит
   (`colleges` не указан — значит для всех).
2. Если подходят несколько записей — побеждает самая узкая: конкретный день
   важнее каникул.
3. Найденная запись даёт плашку на карточке дня (показывается всегда, даже
   если встроенные праздники выключены) и, если есть `times`, — время пар
   этого дня. Его берут карточка, перемены и обеды, подсветка текущей пары,
   напоминания, виджет, «Поделиться днём».

Перемена или обед определяются по разрыву между парами: от 20 минут — обед.

## `lesson_times` — обычное время

```json
{
  "chtotib": {
    "1": { "start": "08:15", "end": "09:45" },
    "2": { "start": "09:55", "end": "11:25" }
  },
  "zabgc": {
    "1": { "start": "08:30", "end": "10:05" }
  }
}
```

Можно и в обёртке `{ "colleges": { … } }` — как поле в `schedule_times.json`.
Время — `Ч:ММ` или `ЧЧ:ММ`. Вместо `start`/`end` можно `from`/`to`.

## `special_days` — особые дни

Ключ — дата `YYYY-MM-DD` или диапазон `YYYY-MM-DD..YYYY-MM-DD` (включительно).

| Поле | Обязательно | Что значит |
|---|---|---|
| `title` | да | заголовок плашки |
| `kind` | нет | `short` — сокращённый, `holiday` — праздник/выходной, `info` — пометка (по умолчанию) |
| `note` | нет | подпись под заголовком |
| `emoji` | нет | значок плашки (по умолчанию ⏱️ / 🎉 / 📌) |
| `color` | нет | цвет плашки и карточки дня, `#RRGGBB` |
| `colleges` | нет | `["chtotib"]`, `["zabgc"]` — не указан, значит для всех |
| `noClasses` | нет | `true` — «Пар нет», если нет `note` |
| `times` | нет | время пар дня: номера пар, по техникумам или имя пресета |

### Сокращённый день по пресету (сокращёнка ЧТОТиБ)

Пресет задаётся один раз в `presets`, дни ссылаются на него по имени:

```json
{
  "presets": {
    "chtotib_astro": {
      "1": { "start": "08:15", "end": "09:15" },
      "2": { "start": "09:25", "end": "10:25" },
      "3": { "start": "10:35", "end": "11:35" },
      "4": { "start": "12:05", "end": "13:05" },
      "5": { "start": "13:15", "end": "14:15" },
      "6": { "start": "14:25", "end": "15:25" }
    }
  },
  "2026-12-31": {
    "kind": "short",
    "title": "Сокращённый день",
    "note": "Пары по астрономическому часу",
    "colleges": ["chtotib"],
    "times": "chtotib_astro"
  },
  "2027-02-22": {
    "kind": "short",
    "title": "Предпраздничный день",
    "colleges": ["chtotib"],
    "times": "chtotib_astro"
  }
}
```

### Время прямо в дне (для всех техникумов из `colleges`)

```json
{
  "2026-12-30": {
    "kind": "short",
    "title": "Сокращённый день",
    "colleges": ["chtotib"],
    "times": {
      "1": { "start": "08:15", "end": "09:00" },
      "2": { "start": "09:10", "end": "09:55" }
    }
  }
}
```

### Разное время для разных техникумов в один день

```json
{
  "2026-12-31": {
    "kind": "short",
    "title": "Сокращённый день",
    "times": {
      "chtotib": { "1": { "start": "08:15", "end": "09:15" } },
      "zabgc":   { "1": { "start": "08:30", "end": "09:30" } }
    }
  }
}
```

### Праздник и каникулы

```json
{
  "2026-11-04": {
    "kind": "holiday",
    "title": "День народного единства",
    "noClasses": true
  },
  "2026-12-29..2027-01-11": {
    "kind": "holiday",
    "title": "Зимние каникулы",
    "noClasses": true,
    "emoji": "❄️",
    "color": "#5AC8FA"
  }
}
```

### Просто пометка

```json
{
  "2026-10-31": {
    "title": "Занятия по расписанию понедельника",
    "colleges": ["zabgc"],
    "emoji": "🔁"
  }
}
```

## Частые ошибки

- **Перепутаны день и месяц** (`2026-31-12`) — запись пропускается, `check.dart`
  об этом скажет.
- **Нет `title`** — запись пропускается.
- **Опечатка в имени пресета** — у дня не будет своего времени (останется
  обычное); `check.dart` скажет, какого пресета нет.
- **Битый JSON** — консоль Firebase не даст сохранить параметр типа JSON.

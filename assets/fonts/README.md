# Шрифты

## Ndot 77 (Ndot77JPExtended)

Шрифт **Ndot 77** использует файл `Ndot77JPExtended.ttf` из этой папки. Он уже подключён в `pubspec.yaml`. Выберите «Ndot 77» в настройках приложения.

## Space Grotesk

Шрифт **Space Grotesk** подключён локально из файлов `SpaceGrotesk-*.ttf` и доступен в настройках приложения.

## Pixel (Minecraft)

Пиксельный шрифт **Press Start 2P** подгружается через Google Fonts при первом использовании, отдельные файлы не нужны.

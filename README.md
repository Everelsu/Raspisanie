# Raspisanie

`Raspisanie` — Flutter-приложение для просмотра учебного расписания из систем формата «Экспресс-расписание».

## Основные возможности

- режим студента и преподавателя;
- загрузка и кэширование расписания;
- заметки с карточками, фильтрами, поиском и корзиной;
- локальные уведомления;
- статистика и история расписания;
- настройка внешнего вида и параметров отображения.

## Технологии

- Flutter + Dart;
- локальное хранилище и настройки через `shared_preferences` и SQLite;
- парсинг HTML-страниц расписания;

## Требования

- Flutter SDK (stable);
- установленный Android SDK или Xcode (в зависимости от платформы);
- устройство или эмулятор для запуска.

## Быстрый старт

```bash
flutter pub get
flutter run
```

## Структура проекта

- `lib/app` — запуск приложения, тема, корневая конфигурация;
- `lib/core` — сеть, парсинг, база данных, общие виджеты и сервисы;
- `lib/features/schedule` — расписание, фильтры, история, уведомления;
- `lib/features/notes` — заметки, редактор, поиск, корзина;
- `lib/features/settings` — пользовательские настройки;
- `lib/features/statistics` — статистические экраны.
